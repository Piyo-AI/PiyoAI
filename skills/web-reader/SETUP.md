# Set up the web reader

Nothing to set up: no accounts or keys.

## Try it

1. Say: "Summarize https://example.com in two sentences."
2. Piyo fetches the page and answers from its text, naming the page as the source.

## Things worth knowing

- It reads public pages only. Pages that need a login, addresses on your own network and pages that load their
  content with scripts are not readable this way; for scripted pages ask Piyo to use the browser instead
  (see **Browse the web**).
- If a page tries to give Piyo instructions, Piyo ignores them and tells you.

## What this skill can do

- Fetch the text of one public web page at a time. Nothing else.
