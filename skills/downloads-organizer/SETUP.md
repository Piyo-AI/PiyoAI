# Set up the downloads organizer

The organizer sorts the files in one folder into sub-folders by type. It never deletes anything.

## Allow the folder

1. Open **Settings > Folders** and add the folder you want tidied, for example your `Downloads` folder.
   Piyo refuses broad places such as a whole drive or your home folder; pick the specific folder.
2. Leave **no prompts for changes** off at first. Piyo then asks before each folder it creates and each file it
   moves, so you can watch what it does. Turn it on for that folder later if the questions become tiresome.

## Try it

1. Say: "Tidy my Downloads folder."
2. Piyo lists the files and proposes a plan (how many files go into Images, Documents, and so on). Nothing
   moves until you agree.
3. Approve the plan. Check the folder afterwards: files that would have overwritten something are skipped and
   reported.

## What this skill can do

- List files, create folders and move files inside folders you approved. Nothing else.
- It needs no accounts, keys or internet access.
