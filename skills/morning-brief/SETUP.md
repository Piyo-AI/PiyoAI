# Set up the morning brief

The brief reads your calendar and unread mail and checks the weather. It only reads: it never sends, creates or
changes anything. Weather comes from Open-Meteo, which needs no account; only the city you name is sent.

## Connect Google

The brief uses the same Google connection as Gmail and Calendar. If you have not set it up, follow the full
guide.

## Run it

running the brief every morning automatically comes in a later version.)
