# Set up web research

Piyo searches the web with the Brave Search API, reads the best results and answers with sources. You need a
Brave Search API key.

## Get a key

1. Go to <https://brave.com/search/api/> and create an account.
2. Choose a plan (Brave shows which plans are free and their limits) and create an API key.
3. Copy the key.

## Add the key to Piyo

1. Open **Settings > Web search**.
2. Paste the key and press **Save**. The label changes to **key saved**. The key is kept in your operating
   system's keychain, not in a file.

## Try it

1. Say: "What changed in the latest Python release? Give me sources."
2. Piyo searches, opens one to three results, and answers with the pages it used.

## Things worth knowing

- Your search words are sent to Brave. Piyo avoids putting your private details into a query, and asks you
  first if a search would contain something it read from your files or email.
- If the key is missing Piyo tells you to add one. To remove it later use **Remove key** on the same page.

## What this skill can do

- Search the web and read public pages. It needs the Brave key above and no other account.
